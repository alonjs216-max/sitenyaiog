# Гостиница «Соболь» — сайт

Сайт гостиницы «Соболь» (Нягань, 3-й микрорайон, 15/2) на одной странице. Номер выбирают, «снимая ключ» с ключницы. Есть галерея номеров с полноэкранным просмотром и свайпами, рассказ «Один день в гостинице», отзывы, карта и реквизиты для звонка.

Статика без сборки: `index.html`, `styles.css`, `app.js`. Готов к GitHub Pages.

Включить Pages: Settings → Pages → Deploy from a branch → `main` / `(root)`.
